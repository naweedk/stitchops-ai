# StitchOps AI

> AI-powered manufacturing management platform for small garment businesses.

**Status:** 🚧 Under active development

---

## Overview

StitchOps AI helps garment manufacturers manage:

- Customers and Orders
- Workers and Production
- Inventory
- Business Analytics
- AI-powered Insights

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 16, React 19, TypeScript, MUI v7 |
| Backend | NestJS 12, TypeScript, REST API |
| Database | PostgreSQL, Prisma ORM |
| AI | Google Gemini API (backend only) |
| Package Manager | pnpm |

---

## Project Structure

```
stitchops-ai/
├── frontend/   — Next.js App Router application (port 3000)
└── backend/    — NestJS REST API (port 4000)
```
